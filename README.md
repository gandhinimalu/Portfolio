# Gandhini Malu T — Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript. The resume PDF is included in `assets/`.

## Preview locally
Open `index.html` in a browser. An internet connection is used for the Google Fonts import; the page otherwise uses local files.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `gandhini-portfolio`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder (including the resume PDF). Upload the files/folders themselves, not the ZIP file.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
7. Wait for GitHub Pages to publish. The URL will look like `https://YOUR-USERNAME.github.io/gandhini-portfolio/`.
8. Open the published link on both desktop and mobile and test the resume download before submitting.

## Before submitting
- Confirm that all resume details are accurate and current.
- Add your actual LinkedIn/GitHub profile URLs if you want them included.
- Check whether the placement portal accepts a public website link and whether it also requires a separate resume upload.
